## Decision

The Product Owner approves one bounded corrective Wave 2 attempt after the stopped
`V05-W2-01` attempt. This is not a waiver of network denial or any installation control.

The corrective attempt must:

1. disable every enabled physical network adapter, including Ethernet and Wi-Fi, before the
   offline installation window;
2. re-prove from the elevated context that no default route, DNS, HTTP, HTTPS, proxy, or
   Microsoft endpoint is reachable immediately before installer execution;
3. omit the unsupported `/logpath` argument and rely only on the installer's supported native
   logging, copied into private evidence after execution;
4. install only `OptionId.DeploymentTools` from the accepted Wave 1 layout;
5. apply only the accepted KB5101684 servicing MSP set;
6. restore adapters to their enabled/disabled configuration after the offline window;
7. stop on the first mismatch, unexpected prompt, network restoration, installer error,
   unplanned host delta, or restart requirement; and
8. receive no further retry without another explicit Product Owner decision.

No answer-media, VM, candidate, fixture, A12, Quality, WP4, merge, publication, or release work
is authorized.
