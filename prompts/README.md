| Field | Value |
|---|---|

| Status | Draft |
| Version | 0.1.0 |
| Owner | Jason |
| Revised | 2026-07-27 |
| Related | [AI Behavior Standard](../docs/AI_BEHAVIOR_STANDARD.md) |

Prompts belong here when they are reusable engineering assets. Personal prompts and live session output belong in The BRAIN. Each future prompt should state its objective, permitted inputs, prohibited actions, output contract, provider assumptions, and version.

No prompt grants authority beyond the user's task or the repository's permission rules.
