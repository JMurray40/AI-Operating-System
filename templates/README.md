Templates use `{{placeholders}}` so they are tool-agnostic. A vault installer may adapt these to Obsidian Templates or Templater syntax without changing the underlying fields.

| Template | Purpose |
|---|---|
| [Project dashboard](project-dashboard.md) | Canonical project home and resume context |
| [Decision record](decision-record.md) | Durable choice and rationale |
| [Session summary](session-summary.md) | Outcome of meaningful AI or work session |
| [Research note](research-note.md) | Question-driven investigation |
| [Concept note](concept-note.md) | Reusable cross-project knowledge |
| [Daily note](daily-note.md) | Daily focus and audit trail |
| [Meeting note](meeting-note.md) | Preparation, outcomes, and actions |
| [Resource note](resource-note.md) | Pointer to an external authoritative asset |
